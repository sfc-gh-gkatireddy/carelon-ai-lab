# Elevance AI Lab — Build a Member Intelligence Agent on Snowflake

Hands-on lab for building an agentic AI experience on Snowflake for a
healthcare payer: structured claims analytics (Cortex Analyst), RAG over
benefit policy documents (Cortex Search), AI document extraction
(AI_EXTRACT), claim classification (AI_CLASSIFY), all orchestrated by a
Cortex Agent and surfaced in Snowflake CoWork.

**Lab guide:** https://sfc-gh-gkatireddy.github.io/elevance-ai-lab/

## Repository structure

```
elevance-ai-lab/
├── index.html                    # the entire lab guide (GitHub Pages)
├── README.md
└── assets/
    ├── data/                     # synthetic payer CSVs (~185K rows total)
    │   ├── members.csv           #   10,000 enrollees
    │   ├── medical_claims.csv    # ~116,000 claim lines
    │   ├── pharmacy_claims.csv   # ~54,000 prescription fills
    │   └── providers.csv         #   2,000 providers
    ├── documents/                # synthetic benefit policy documents
    │   ├── formulary_guidelines.txt
    │   ├── medical_benefits_summary.txt
    │   ├── quality_stars_measures.txt
    │   ├── pa_denial_letter.pdf  # synthetic PA denial letter (for AI_EXTRACT)
    │   └── generate_pa_denial_pdf.py
    ├── semantic_models/
    │   └── member_intelligence.yaml   # fallback if Autopilot is unavailable
    └── sql/
        ├── setup.sql             # full bootstrap: DB, tables, role, data load
        └── generate_data.py     # synthetic data generator (reproducibility)
```

## How the lab uses this repo

The repo does double duty: it hosts the lab guide (GitHub Pages) **and**
serves as the data source. Attendees create a Snowflake Git Repository
object pointing at this repo, then run:

```sql
EXECUTE IMMEDIATE FROM @ELEVANCE_LAB_REPO/branches/main/assets/sql/setup.sql;
```

which loads the CSVs and creates the full lab environment. No ZIP
downloads, no external file hosting.

## Enabling GitHub Pages

1. Repo Settings → Pages
2. Source: Deploy from a branch — `main` / `(root)`
3. Site goes live at `sfc-gh-gkatireddy.github.io/elevance-ai-lab/`

## Data disclaimer

All data in this repository is **100% synthetic** and was purpose-built for
this lab. It was generated by `assets/sql/generate_data.py` (seeded, so it
is reproducible). No real member, patient, or PHI data is used at any point.
